# Security

wortnetz is a static page: no server-side code, no accounts. Games and settings stay in the
browser's storage; a backup or a debug report is a file the player saves and opens themselves.
What the page may load is limited by a Content-Security-Policy in `index.html`.

## Reporting a problem

Please report security problems privately, through GitHub's "Report a vulnerability" button on
the repository's Security tab. Include what you did and what happened. If a backup file is part
of it, a made-up one is enough: yours lists your games.
